Описание файлов данных, входящих в набор.

1. movies.csv
Содержит информацию о фильмах. Поля: movieId (уникальный идентификатор фильма), title (название с годом выпуска), genres (жанры, разделённые символом |).

2. ratings.csv
Содержит оценки пользователей. Поля: userId (идентификатор пользователя), movieId (идентификатор фильма), rating (оценка от 0.5 до 5.0), timestamp (время в формате Unix).

3. tags.csv
Содержит теги, присвоенные пользователями фильмам. Поля: userId, movieId, tag (текст тега), timestamp.

4. users.txt
Содержит информацию о пользователях. Поля разделены символом |: userId, имя, email, пол, дата регистрации, профессия.

5. genres.txt
Содержит список всех жанров фильмов. Каждый жанр указан на отдельной строке.

6. occupation.txt
Содержит список всех профессий пользователей. Каждая профессия указана на отдельной строке.

7. ratings_count.txt
Содержит статистику по количеству оценок для пользователей: минимальный и максимальный id с числом повторений.

8. sqlite.txt
Содержит информацию о версии SQLite, использованной при работе с данными.
